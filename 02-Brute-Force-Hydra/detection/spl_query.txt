Splunk Detection Engineering
Detection Name:
Web Login Brute Force Detection
=========================================================

1. Detection Objective
----------------------

The objective of this detection is to identify potential brute force attacks
against the DVWA web application by monitoring repeated HTTP POST authentication
requests originating from the same source IP address within a defined time window.

Unlike traditional authentication monitoring, this detection focuses on web
application access logs generated by Apache rather than Windows Security Events.
The rule is designed to identify automated password guessing activity before a
successful compromise occurs.


MITRE ATT&CK:
T1110 – Brute Force

Severity:
High

Log Source:
Apache Access Logs

Sourcetype:
access_combined

---------------------------------------------------------

2. Detection Strategy
---------------------

This detection follows a threshold-based methodology.

Instead of identifying a single failed login attempt, the rule measures login
frequency over time.

Detection Logic:

• Monitor only HTTP POST requests.
• Filter requests targeting /dvwa/login.php.
• Group events by client IP.
• Aggregate events within a 30-second window.
• Count authentication attempts.
• Trigger when attempts exceed the configured threshold.

This approach minimizes false positives while effectively identifying automated
credential attacks.

=========================================================# Splunk Detection Query - Web Login Brute Force

## Detection Name

```text
Web Login Brute Force Detection
```

## Description

Detects multiple HTTP POST login attempts against the DVWA login page from the same source IP within a short time window.

## SPL Query

```spl
index=main sourcetype=access_combined method=POST uri="/dvwa/login.php"
| bin _time span=30s
| stats count as attempts values(useragent) as useragent earliest(_time) as first_attempt latest(_time) as last_attempt by clientip
| where attempts >= 5
| eval first_attempt=strftime(first_attempt,"%Y-%m-%d %H:%M:%S")
| eval last_attempt=strftime(last_attempt,"%Y-%m-%d %H:%M:%S")
| eval Severity="High"
| eval Technique="MITRE ATT&CK T1110 - Brute Force"
| eval Detection="DVWA Web Login Brute Force"
| sort -attempts
```

---

# Detection Logic Explanation

The query performs the following actions:

1. Filters web access logs related to the DVWA login endpoint.

```text
/dvwa/login.php
```

2. Monitors HTTP POST requests generated during authentication attempts.

3. Groups events by source IP within a 30-second time window.

4. Counts the number of login attempts.

5. Triggers detection when:

```text
attempts >= 5
```

6. Adds investigation metadata:

* Severity
* MITRE ATT&CK Technique
* Detection Name
* First Attempt Time
* Last Attempt Time
