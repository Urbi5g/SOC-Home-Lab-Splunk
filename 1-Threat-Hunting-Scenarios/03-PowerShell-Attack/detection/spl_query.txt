============================================================
SOC HOME LAB — SPLUNK DETECTION
Incident: PowerShell Attack
MITRE ATT&CK: T1059.001
============================================================

Purpose:
Detect suspicious PowerShell execution originating from cmd.exe
and identify PowerShell commands using encoded command-line
arguments.

Index:
main

Sourcetype:
XmlWinEventLog:Microsoft-Windows-Sysmon/Operational


============================================================
1. PRIMARY DETECTION — PowerShell Spawned by CMD
============================================================

index=main sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
Image="*powershell.exe*"
ParentImage="*cmd.exe*"
| table _time host User Image ParentImage CommandLine ProcessId
| sort -_time


Detection Logic:
- Identifies PowerShell execution.
- Checks whether PowerShell was launched by cmd.exe.
- Displays the user, host, process relationship, and command line.
- Useful for identifying suspicious command interpreter chains.


============================================================
2. ENCODED POWERSHELL DETECTION
============================================================

index=main sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
Image="*powershell.exe*"
(CommandLine="*-e *" OR CommandLine="*-enc *" OR CommandLine="*-EncodedCommand*")
| table _time host User Image ParentImage CommandLine ProcessId
| sort -_time


Detection Logic:
- Searches for PowerShell encoded-command parameters.
- Detects common forms:
    - -e
    - -enc
    - -EncodedCommand
- Encoded PowerShell can be used to obscure malicious commands
  from basic command-line inspection.


============================================================
3. COMBINED DETECTION — CMD + ENCODED POWERSHELL
============================================================

index=main sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
Image="*powershell.exe*"
ParentImage="*cmd.exe*"
(CommandLine="*-e *" OR CommandLine="*-enc *" OR CommandLine="*-EncodedCommand*")
| table _time host User Image ParentImage CommandLine ProcessId
| sort -_time


Detection Logic:
This is the primary high-confidence detection used in the
PowerShell attack simulation.

The detection requires three conditions:

1. PowerShell is executed.
2. PowerShell was spawned by cmd.exe.
3. The PowerShell command line contains an encoded-command
   parameter.

This combination provides stronger detection confidence than
detecting PowerShell execution alone.


============================================================
4. POWERSHELL PROCESS TIMELINE
============================================================

index=main sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
Image="*powershell.exe*"
| stats count min(_time) as first_seen max(_time) as last_seen
  values(ParentImage) as ParentImage
  values(User) as User
  values(CommandLine) as CommandLine
  by host Image
| convert ctime(first_seen) ctime(last_seen)
| sort -last_seen


Purpose:
Provides a high-level timeline of PowerShell execution across
the monitored Windows endpoint.

============================================================
10. POWERSHELL OBFUSCATION / ENCODED COMMAND INVESTIGATION
============================================================

index=main sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
Image="*powershell.exe*"
(CommandLine="*-e *"
 OR CommandLine="*-enc *"
 OR CommandLine="*-EncodedCommand*"
 OR CommandLine="*FromBase64String*")
| eval DetectionReason=case(
    match(CommandLine,"(?i)-encodedcommand"),"EncodedCommand",
    match(CommandLine,"(?i)-enc"),"Encoded PowerShell",
    match(CommandLine,"(?i)-e "), "Encoded PowerShell",
    match(CommandLine,"(?i)FromBase64String"),"Base64 Decoding",
    true(),"PowerShell Obfuscation"
  )
| table _time host User Image ParentImage CommandLine ProcessId DetectionReason
| sort -_time


Purpose:
Adds a DetectionReason field to help the SOC analyst quickly
understand why an event was selected.
